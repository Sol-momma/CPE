    CPE 考え方の型

    56問は、だいたい8つの型の組み合わせでできています。問題文を読んだら、まず下の5つの質問に答えて、どの型かを当てます。コードはそのあとです。

    解く前の5つの質問

    1. 入力はいつ終わる？

      問題文の Input の書き方で、ループの形が決まります。

      問題文のサインループの形例
      until end of file / 個数が書いていないwhile (cin >> x)CPE26101, 26111, 26121
      A line containing 0 ends the inputif (x == 0) break;CPE26041, 26042, 26051
      The first line contains the number of test casescin >> t; while (t--)CPE26012, 26043, 26113
      line / sentence（空白を含む1行）getline(cin, s)CPE26024, 26133, 26143
    2. 数はどれくらい大きい？

      型の選び方は 大きさで型を選ぶ を見てください。

    3. 何を答える問題？

      「何個？」なら数える型、「順番に並べて」なら並べる型、「〜かどうか」なら判定です。答えの形を先に決めます。

    4. 全部試しても間に合う？

      目安は 1秒でおよそ1億回（108）です。範囲が小さければ全部試すのが一番安全で、間に合わないときだけ公式を探します。

    5. 出力の形は？

      単数と複数（operation / operations）、空行がケースの「間」か「後」か、小数は何桁か、Case 1: の書き方。正しく解けていても、ここを間違えると不正解になります。

    8つの型

    簡単な順

    上から順に解くと、前の問題で使った書き方が次の問題でそのまま使えます。問題を押すと、下の「問題を読む」に問題文が出ます。

    56問マップ

    型を押すと、その型を使う問題だけが光ります。問題を押すと、下の「問題を読む」に問題文（PDF）・単語・日本語訳・サンプル・考え方・解答コードが出ます。
